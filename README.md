## 📖 About the Platform

**Global Shine Digital Solutions Pvt. Ltd.** is an enterprise-grade digital solutions and IT services portal built with modern web standards, featuring:

- **Corporate IT Presence**: Tailored for pure IT company positioning with clean, high-performance typography and corporate slate/indigo palette.
- **Real-Time Enquiry & Lead Management**: Website inquiries immediately flow into the Admin CRM with interactive status tracking (`🟢 New`, `🟡 In Discussion`, `🔵 Quotation Sent`, `🏆 Won`, `❌ Lost`) and team/partner assignment controls.
- **WhatsApp & Phone Connect**: Quick one-click WhatsApp chat and direct calling links for inquiries.
- **Client Portfolio**: Real-world showcase of enterprise client projects across Healthcare, Retail, Education, and Manufacturing.
- **Multi-Role Security**: Role-based access control for Admins, Staff Team Members, Channel Partners, and Clients.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Modern CSS, Tailwind CSS, FontAwesome 6, Google Inter Fonts
- **Backend**: Python 3, Flask, SQLite3, Werkzeug Security
- **Static Export Engine**: Built-in Python generator (`export_static.py`) ensuring 100% full offline & static hosting compatibility for **GitHub Pages**, **Netlify**, and **Vercel**
- **Hosting**: GitHub Pages (`https://ayushikhare26.github.io/Global-Shine-Platform/`)

## 💻 Running the Project Locally

### 1. Clone the repository
```bash
git clone https://github.com/ayushikhare26/Global-Shine-Platform.git
cd Global-Shine-Platform
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Flask server
```bash
python app.py
```
Open [http://localhost:5000](http://localhost:5000) in your browser.

### 4. Build Static Site for GitHub Pages
```bash
python export_static.py
```
